# air_quality_monitoring

Air quality monitoring system (group 1 project 2)

## What the AQMS Project Does

The Air Quality Monitoring System is a mobile application designed to help users monitor air-quality conditions in their selected location. The application retrieves current air-quality information from an external API and displays the Air Quality Index (AQI), air-quality category, pollutant levels, and general health guidance in a clear and accessible format.

The system also allows users to submit and view community reports about local air-quality conditions. It provides alerts when air-quality levels become unhealthy, helping users make better-informed decisions about outdoor activities.

The application includes user authentication, an AQI dashboard, community reporting, and alert features. It is being developed using Flutter and Firebase, with GitHub used for collaborative version control and Jira used for project planning and progress tracking.

# What the folders mean
models: Defines the structure of data, such as AQI values or community reports.
screens: Contains complete application pages.
services: Communicates with Firebase, APIs and device services.
widgets: Contains smaller reusable interface components.
core: Contains resources used throughout the whole application.
navigation: Controls application routes and the bottom navigation bar.
